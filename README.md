# Адаптивная карточка мероприятия с оплатой через Stripe и QR

Этот проект содержит **React компонент** для отображения **карточки мероприятия** с функционалом покупки билетов. Он поддерживает **платежи через Stripe**, **мобильные платежи по QR-коду**, **Apple Pay / Google Pay** и **украинские банки (Monobank, PUMB)**. Весь текст пользовательского интерфейса локализован на **украинском языке**.

## ✨ Возможности
- Адаптивный макет (слева: информация о мероприятии, справа: форма оплаты)
- Селектор количества билетов с отображением общей цены в реальном времени
- Опции оплаты:
  - **Apple Pay** / **Google Pay**
  - **Оплата картой через Stripe**
  - **Украинские банки (Monobank, PUMB)**
  - **Модальное окно с QR-кодом для мобильной оплаты**
- Валидация формы с помощью **Formik + Yup**
- Интеграция Stripe с `CardElement`
- Стилизовано с помощью CSS Modules (`EventCard.module.css`)
- Доступные кнопки, формы и модальное окно

---

## 🛠️ Стек Технологий
- **React 18+**
- **Formik** + **Yup** (обработка и валидация форм)
- **Stripe React SDK** (`@stripe/react-stripe-js`)
- Иконки **FontAwesome**
- **CSS Modules** для изолированных стилей
